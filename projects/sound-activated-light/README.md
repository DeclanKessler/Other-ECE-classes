# Sound-Activated Light — LTspice Draft

An initial LTspice circuit draft from my Circuits II project files.

## Circuit file

[Open or download the schematic](First-draft.asc).

The draft includes an **NE555 timer**, a **2N3904 transistor**, a simulated pulse input, and an LED/load branch. It is an early design artifact rather than a complete record of the final hardware.

## Inspecting the design

1. Download `First-draft.asc` and open it in LTspice.
2. Review the input model, transistor stage, timer connections, and component values.
3. Check the draft's simulation settings and model availability before running it.

My résumé describes a sound-activated nightlight project involving microphone triggering, background-noise filtering, timer-circuit testing, and documented design iterations.
